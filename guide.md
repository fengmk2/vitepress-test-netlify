# Introduction

Welcome to vitepress-test-netlify!

This is a [VitePress](https://vitepress.dev) site deployed to [Netlify](https://netlify.com).

## Getting Started

```sh
npm install
npm run docs:dev
```

## Build

```sh
npm run docs:build
```

## Deploy

This site is automatically deployed to Netlify. See the [netlify.toml](https://github.com/fengmk2/vitepress-test-netlify/blob/main/netlify.toml) for configuration.
